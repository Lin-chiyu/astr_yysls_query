# astrbot_plugin_yanyun_query

AstrBot 插件:查询《燕云十六声》角色数据,渲染为**精美图片卡片**直接发送,
并提供**流派养成对标分析**(基于内置的 12 流派攻略文档)。
群友可私聊机器人**扫码登录后自动绑定自己的角色**,WebUI 面板同样支持一键扫码获取凭据。

**协议已实测打通**(2026-11),数据来自网易大神 datamsapi 生涯接口。

## 功能亮点

- **总览合并卡**:一张长图看全部——角色档案(功力/成就/称号/时装)、区域探索(进度条+宝箱/蹊跷)、
  流派配置(套装/功法/心法/奇术)、面板最终属性、装备词条按装备分列、合并汇总
- **养成分析卡**:拿角色实际数据对标内置的流派攻略——词条数量缺多少、哪个部位的词条该洗、
  战力模块达标情况、带部位的养成方向
- **流派识别**:主副功法组合自动匹配流派(破竹樽/鸣金霆/牵丝玉等 12 系),双向匹配
- **图片直发**:卡片渲染成功直接发图;渲染失败自动回退合并转发表文,永不静默失败
- **自然语言唤起**:配置大模型后,"看看我的角色""帮我分析养成" 直接触发;
  大模型还会基于对标数据写一段养成推荐

## 数据来源与鉴权原理(一段话)

网易没有开放 API,大神 App 端接口有私有加密签名无法模拟。本插件走大神**网页版**
的公开体系:凭据 = `getReportToken` 签发的**年度 token**(dts=年份),请求校验
`GL-CheckSum = sha1(body + XSRF)`,XSRF/设备号均可自制——所以机器人服务端只需要
token 本身,签发后完全自动化。token 与角色绑定,一个 token 查一个角色。

## 安装

> 需要 AstrBot **>= 4.27.5**(WebUI 面板扫码用);更低的版本查询指令也能用,只是没有面板。

### 方式一:WebUI 安装(推荐)

1. WebUI → 插件 → 安装插件 → 填仓库地址 `https://github.com/Lin-chiyu/astr_yysls_query`
2. 装完重载插件,日志出现 `[燕云查询] 已加载` 即成功
3. 绑定角色:群友私聊机器人说「燕云登录」扫码绑定;或管理员在插件详情页「燕云凭据获取」面板扫码

### 方式二:手动放进 data/plugins

```bash
cd /path/to/AstrBot/data/plugins
git clone https://github.com/Lin-chiyu/astr_yysls_query.git astrbot_plugin_yanyun_query
```

依赖写在 `requirements.txt`(aiohttp / playwright / pillow),AstrBot 安装插件时会自动装;
如果没装上,用 AstrBot 自己的 Python 环境执行 `pip install -r requirements.txt`。

### 浏览器环境(全自动)

图片卡片和扫码登录都依赖无头浏览器,插件会自己处理:

- 没有 playwright 包 → 自动 `pip install playwright`
- 没有可用浏览器 → 自动下载 chromium(约 150MB,默认 npmmirror 镜像);有系统 Chrome/Edge 就直接复用,不下载
- 想关掉自动安装:`auto_install_browser: false` / `preinstall_browser: false`
- Linux 裸机提示缺系统库时,以 root 执行一次 `playwright install-deps chromium`

### 更新

```bash
cd /path/to/AstrBot/data/plugins/astrbot_plugin_yanyun_query
git pull
```

然后重启 AstrBot(或在 WebUI 插件页重载),日志里能看到加载的版本号。

### 注意

- 不要改动插件目录里的 `gamedata/`(游戏映射表 + 流派攻略文档,渲染与对标都依赖它)
- 目录名保持 `astrbot_plugin_yanyun_query`:AstrBot 用目录名识别插件,改名会加载失败
- 服务器 `git pull` 卡住(常见于国内直连 GitHub)时,可以本地打包再 scp 上去,或用插件市场的更新

## 凭据获取

### 方式一:群友私聊自助扫码(推荐)

1. 群友**私聊**机器人说一句想绑定角色的话,例如「燕云登录」(群里发会提示转私聊)
2. 机器人发出登录二维码 → 用手机大神 App 扫码登录
3. 扫码成功后自动读取该账号下的燕云角色:只有一个角色直接绑定,多个则回复序号选择
4. 自动签发 token、写入配置并绑定 —— 全程无需管理员,事先也不用知道角色编号

> 每次只有一个扫码任务进行中(后来者会收到"稍后再试");二维码约 2 分钟有效。

### 方式二:WebUI 面板一键获取(管理员)

1. WebUI → 插件 → 燕云十六声查询 → 详情页 → 打开「燕云凭据获取」面板
2. 点「一键获取 token」→ 面板显示登录二维码(日志页同步输出点阵版)
3. 手机大神 App 扫码登录 → 面板列出该账号下的燕云角色
4. 只有一个角色时自动签发;多个角色时点选要添加的那个 → 自动写入插件配置
5. 面板或聊天里查一次凭据状态即可确认

> - 二维码约 2 分钟有效,过期请「取消」后重新获取
> - token 绑定角色:查询多个角色就分别用对应账号扫码,配置里会自动追加
> - token 是敏感凭据,请勿外传

### 方式三:手动(降级方案)

1. 电脑浏览器打开 [ds.163.com](https://ds.163.com),手机大神 App 扫码登录
2. F12 → Console(粘贴被拦就先输入 `allow pasting` 回车)
3. 粘贴 `tools/get_token.js` 全部内容 → 回车
4. 从绿色输出复制 **role_id / token / dts** 三行,填进插件配置 `dashen_accounts`

## 配置说明

| 配置项 | 说明 |
|---|---|
| `dashen_accounts` | 凭据池:`[{name, role_id, token, dts, enabled}]`,每项一个角色 |
| `server` | 区服标识,默认 `1`(正式服) |
| `timeout` | 请求超时秒数,默认 15 |
| `cooldown_seconds` | token 失效(401)后冷却秒数,默认 3600 |
| `auto_install_browser` | 缺无头浏览器时自动安装,默认开 |
| `preinstall_browser` | 插件加载时后台预装浏览器,默认开 |
| `browser_download_mirror` | chromium 下载镜像,默认 npmmirror |
| `profile_image` | 总览合并卡(角色档案+探索+流派+面板+词条)以图片发送,默认开 |
| `advisor_image` | 养成分析卡(词条/战力对标+养成方向)以图片发送,默认开 |

> 所有图片卡渲染失败都会**自动回退为文本输出**,不会静默失败。

| `燕云查询 <角色编号>` | `yy查询` | 查凭据池内的角色(同「燕云我的」总览卡) |

| `燕云帮助` | `yy帮助` | 指令说明 |

> 图片卡发送失败时,以上所有查询自动回退为合并转发表文;配置开关可分别关闭图片输出。

## 流派养成对标(燕云分析)

内置 12 系流派攻略文档(破竹/鸣金/裂石/牵丝,`gamedata/liupai_docs/`),分析流程:

1. **流派识别**:主副功法组合双向匹配(悬身拳法+断水双诀 → 破竹樽)
2. **词条数量对标**:角色实际词条按部位/名称统计,对照攻略推荐数量,给出 缺/可保留/优先更换/过渡
3. **战力模块对标**:最小/最大外功、属性攻击、精准/会心/会意率 对照攻略达标值
4. **养成方向**:缺口定位到具体部位(如"胸甲的最大外功攻击、环的最大外功攻击/势优先更换"),附可洗词条来源

配有大模型时,AI 会基于对标数据额外写一段自由发挥的养成推荐(不编造数据)。

## 自然语言唤起(可选)

AstrBot 配置了大模型提供商后,可以直接用自然语言触发(基于 LLM 工具调用):

- "看看我的燕云角色" / "查一下探索度" → 总览合并卡
- "帮我分析养成" / "我的词条该怎么洗" → 养成分析卡 + AI 养成推荐
- "我的面板属性怎么样" / "家园数据" → 详情与面板属性
- "PVP 数据" → 战绩

已注册的 LLM 工具:yanyun_query_profile / yanyun_query_detail / yanyun_analyze_build / yanyun_query_pvp。
不配置大模型也不影响指令使用(图片照发,少一段 AI 推荐)。

## 已知限制

- **只能查凭据池内的角色**:token 绑定角色,谁的 token 查谁的角色;
  群友可自己私聊扫码登录拿到凭据,不需要管理员代为配置
- token 年度有效;失效后查询报"token 失效",面板重新扫码或手动更新即可
- 图片卡渲染依赖 playwright + chromium(或系统 Chrome/Edge);Windows/Linux 均支持,
  探测顺序为 chromium → 系统 Chrome → 系统 Edge;失败自动回退文本
- 流派攻略文档为当前版本数据(`gamedata/liupai_docs/`),版本更新后可能需要社区更新
- PVP 的 type 字段含义待确认,后续版本解析具体战绩
- 非公开接口,网易随时可能调整;端点/签名逻辑集中在 `api.py`,便于跟进

## 实测工具(tools/)

- `probe.py` — 独立实测脚本,可脱离 AstrBot 验证凭据可用性
