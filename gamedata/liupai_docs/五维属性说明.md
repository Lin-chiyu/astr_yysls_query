# 五维属性说明

燕云十六声的角色五维为:**体、劲、御、敏、势**。主副武器的属性都会计入人物总属性。

## 五维各自管什么

| 五维 | 作用定位                                |
| ---- | --------------------------------------- |
| 体   | 气血(最大生命值),生存向                 |
| 劲   | 外功攻击(最小+最大都加),输出面板核心    |
| 御   | 气血 + 外功防御,防御向;输出词条一般不选 |
| 敏   | 最小外功 + **会心率**,会心流核心        |
| 势   | 最大外功 + **会意率**,会意流核心        |

## 与流派词条推荐的对应

- **会心流派**(如破竹系多数、牵丝系输出流派):优先 **敏**,搭配劲、大小外功词条
- **会意流派**(鸣金虹 / 鸣金影 / 鸣金霆):优先 **势**,搭配劲、大外
- **输出通用**:劲 + 大外/小外是面板基本盘;御只适合防御Build
- 防具(冠胄/胸甲、胫甲/腕甲)词条优先会心/会意/精准,与五维形成互补
