# 裂石钧流派推荐养成

## 配装方案

- **推荐方案**:断岳四件套 & 玄甲四件套(套装:「断」「玄」)

## 调律建议

### 一、不同部位推荐词条

| 部位 | 首词条推荐 | 推荐词条搭配 | 定音推荐 |
| --- | --- | --- | --- |
| 主武器/副武器 | 小外 | 小外、敏、会心、精准、陌刀武学增伤 | 外攻穿透 |
| 环/佩 | 小外 | 小外、敏、会心、精准、全武学增效 | 外攻穿透 |
| 冠胄/胸甲 | 会心/精准 | 会心、精准、小外、敏;属性攻击按可出现部位补齐 | 十方破阵·蓄力技增伤 |
| 胫甲/腕甲 | 会心/精准 | 小外、敏、会心、精准、首领增伤 | 十方破阵·蓄力技增伤 |

### 二、双切小外流词条数量参考

| 词条属性 | 词条数量 |
| --- | --- |
| 最小外功攻击 | 12个 |
| 敏 | 8个 |
| 会心率 | 7个 |
| 精准率 | 2个 |
| 属性攻击词条 | 6个 |
| 神力词条(陌刀武学/全武学/首领增伤) | 5个 |

### 三、调律小技巧

1. **技巧一**:裂石钧以上部位建议和数量参考采用双切小外方案;6 条属性攻击按最大无相攻击 2 条、最大裂石攻击 4 条配置,会心率词条 7 条
2. **技巧二**:本赛季纯唐玩法与双切玩法伤害差距不大,均可以体验。选择纯唐时,武学增伤改为横刀武学增伤,防具定音选择斩雪刀法·轻重击派生技增伤,词条数量按纯唐方案调整
