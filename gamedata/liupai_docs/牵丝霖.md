# 牵丝霖流派推荐养成

## 配装方案

- **推荐方案**:浣花四件套 & 梨雪四件套(套装:「花」「雪」)

## 调律建议

### 一、不同部位推荐词条

| 部位 | 首词条推荐 | 推荐词条搭配 | 定音推荐 |
| --- | --- | --- | --- |
| 主武器/副武器 | 大外 | 大外、劲、会心、敏、小外、扇增伤 | 外攻穿透 |
| 环/佩 | 大外 | 大外、劲、会心、敏、全武学增伤 | 外攻穿透 |
| 冠胄/胸甲 | 会心 | 大外、劲、会心、敏、小外 | 明川药典·治疗技增疗 |
| 胫甲/腕甲 | 劲 | 大外、劲、会心、敏、最小牵丝、对玩家单位增效 | 明川药典·治疗技增疗 |

### 二、纯奶词条数量参考

| 词条属性 | 词条数量 |
| --- | --- |
| 最大外功攻击 | 12个 |
| 劲 | 10个 |
| 会心率 | 5个 |
| 小外 | 4个 |
| 敏 | 4个 |
| 神力词条(扇武学/全武学/玩家增效) | 5个 |

### 三、调律小技巧

1. **技巧一**:以上按纯奶方案推荐,不分配精准率和会意率词条,保证会心率至少 75%;火拳输出奶需使用对应方案
2. **技巧二**:没有外功攻击词条的时候,可以选择牵丝词条代替
