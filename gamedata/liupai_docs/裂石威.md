# 裂石威流派推荐养成

## 配装方案

- **推荐方案**:时雨四件套 & 易相四件套(套装:「雨」「易」)

## 调律建议

### 一、不同部位推荐词条

| 部位 | 首词条推荐 | 推荐词条搭配 | 定音推荐 |
| --- | --- | --- | --- |
| 主武器/副武器 | 大外 | 大外、劲、会心、敏、陌刀武学增伤 | 外攻穿透 |
| 环/佩 | 大外 | 大外、劲、会心、敏、全武学增伤 | 外攻穿透 |
| 冠胄/胸甲 | 会心/精准 | 会心、大外、劲、精准、敏、大本属 | 嗟夫刀法·蓄力技增伤 |
| 腔甲/腕甲 | 劲 | 劲、大外、势、首领增伤 | 嗟夫刀法·蓄力技增伤 |

### 二、不同词条数量参考

| 词条属性 | 词条数量 |
| --- | --- |
| 最大外功攻击 | 12个 |
| 劲 | 10个 |
| 会心率 | 6个 |
| 势 | 5个 |
| 精准率 | 2个 |
| 神力词条(陌刀武学/全武学/首领增伤) | 5个 |

### 三、调律小技巧

1. **技巧一**:优先满足三率 > 考虑外攻或属攻 > 神力词条
2. **技巧二**:大本属收益也不低,不用刻意追求大外
3. **技巧三**:陌刀武学增伤和双首领增伤是刚需,全武学可以尽量追求
4. **会心率参考**:会心率至少达到 56%,达标后结合词条收益分配,避免为继续堆高会心牺牲核心外功
