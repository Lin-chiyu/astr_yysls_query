# 破竹尘流派推荐养成

## 配装方案

- **推荐方案**:连星四件套 & 抱玉四件套(套装:「星」「玉」)

## 调律建议

### 一、不同部位推荐词条

| 部位 | 首词条推荐 | 推荐词条搭配 | 定音推荐 |
| --- | --- | --- | --- |
| 主武器/副武器 | 大外 | 大外、劲、会心、伞增伤 | 外攻穿透 |
| 环/佩 | 大外 | 大外、劲、会心、全武学增伤 | 外攻穿透 |
| 冠骨/胸甲 | 会心 | 大外、劲、会心、敏、精准 | 醉梦游春·武学技增伤 |
| 胫甲/腕甲 | 劲 | 大外、劲、会心、敏、精准、首领增伤 | 醉梦游春·武学技增伤 |

### 二、不同词条数量参考

| 词条属性 | 词条数量 |
| --- | --- |
| 最大外功攻击 | 12个 |
| 劲 | 10个 |
| 会心率 | 8个 |
| 敏 | 3个 |
| 精准率 | 2个 |
| 神力词条(伞武学/全武学/首领增伤) | 5个 |

### 三、调律小技巧

1. **技巧一**:优先保证三率健康的情况下,再去追求外功攻击
2. **技巧二**:在外功词条不够的情况下,可以选择大破竹/小外属词条
3. **技巧三**:破竹尘可以选择走小外流,优先选择小外/敏,追求小外高于大外
