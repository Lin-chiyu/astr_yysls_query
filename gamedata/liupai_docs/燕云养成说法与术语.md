# 燕云养成说法与术语说明

> 目的:统一燕云相关的输出用语,避免套用其它游戏(暴击/暴伤、元素伤害、洗练、附魔等)的经验说法。
> 整理自官方公告与主流攻略站(游民星空 / 3DM / 17173 / NGA 等),数据随版本变动,以当前赛季为准。

## 一、伤害判定体系(和"暴击"体系完全不同)

燕云的输出判定是**两级判定**,不要用"暴击率/暴击伤害"来表述:

| 术语 | 含义 | 其它游戏近似概念 |
| --- | --- | --- |
| **三率** | 精准率、会心率、会意率的合称 | 无对应说法 |
| **精准率** | 命中敌人有效部位(弱点)的概率,上限 100%,是一切的前提 | 命中率 |
| **会心率** | 精准命中后打出**黄字**额外伤害的概率,上限 80% | 暴击率(但要先过精准) |
| **会意率** | 精准命中后打出**橙字**更高倍率伤害的概率,上限 40% | 高阶暴击 |
| 会心与会意关系 | 触发会意会阻止会心;两者合计超出 100% 的部分无效 | — |

- 攻击构成:精准命中 + 未精准命中;精准命中内再分普通/会心/会意
- 输出建议里说"三率健康"指:精准、会心(或会意)达到流派要求的水平
- **会意流派**(鸣金系)刻意不堆会心/精准,会意靠"势"转化,叫"常规无精准玩法"

## 二、攻击与词条黑话

| 术语 | 含义 |
| --- | --- |
| **大外 / 小外** | 最大外功攻击 / 最小外功攻击词条 |
| **大外流 / 小外流** | 以大外为核心 / 以小外为核心的配装思路(小外流伤害均值更稳定) |
| **本属(大本属/小本属)** | 本系属性攻击词条;收益一般低于外功,可留但优先级低 |
| **无相攻击** | 无相系属攻,可视为本系属攻的一种 |
| **大破竹 / 最大破竹攻击** | 破竹系属攻词条(裂石系同理叫"最大裂石攻击") |
| **神力词条** | 增伤类词条统称(武学增伤、全武学增效、首领增伤、对玩家单位增效等);收益依赖基础面板,社区提醒"不要迷信神力" |
| **武学增伤 / 全武学增效** | 指定武器武学 / 全部武学的增伤,属顶级神力词条 |
| **首领增伤(双首领增伤)** | 对首领单位的增伤;部分流派(裂石威)视为刚需 |
| **四攻** | 大外、小外、大属攻、小属攻四类攻击词条的合称 |

## 三、装备养成动词(不要叫"洗练")

| 术语 | 含义 |
| --- | --- |
| **调律** | 重掷装备词条(随机刷新) |
| **转律** | 固定其它词条、只替换其中一条;关键在于理解词条池,先排除"必定不出"的词条再规划 |
| **定音** | 装备的特殊固定加成选项(如"外攻穿透""九重春色·高频弹道增伤"),按部位成对选择 |
| **承音 / 传律** | 承音装备不可调律转律,只能通过"传律"提升——消耗一件 91 阶满调律金色装备提升选定词条数值(2026-04-30 装备培养优化) |
| **词条数量** | 全身各词条的持有条数(如"最大外功攻击 12 个"),流派攻略的核心指标 |

## 四、流派黑话(社区惯用叫法)

| 说法 | 流派 | 含义 |
| --- | --- | --- |
| **走地玉 / 飞天玉** | 牵丝玉 | 伞+扇双修远程流的两个分支:走地玉贴地输出、几乎不耗耐力,上限高(T0);飞天玉滞空输出,下限高适合新手 |
| **火拳(奶) / 纯奶** | 牵丝霖 | 火拳=战斗型输出奶(心法换怒斩马,兼顾输出与治疗);纯奶=专注治疗量(词条参考那套就是纯奶方案) |
| **双切轴 / 纯唐轴** | 裂石钧 | 双切=横刀↔陌刀易武切换打爆发(当前 T0);纯唐=纯横刀不切刀的替代玩法,伤害差距不大 |
| **走小外流** | 破竹樽/鸢/风/尘等 | 破竹系常见思路:优先小外+敏,追求小外高于大外 |

## 五、机制与手法词

| 术语 | 出处 | 说明 |
| --- | --- | --- |
| **易武** | 通用 | 主副武器切换,派生输出轴的核心(双切即基于此) |
| **特殊技 / 蓄力技 / 轻重击派生技** | 通用定音词 | 各武学技能分类,防具定音按流派核心技能选增伤 |
| **浓醺** | 破竹樽 | 醉饮机制状态,定音"悬身断水·浓醺技能增伤"围绕它 |
| **阴阳迷踪 / 千灯一月** | 破竹樽 | 奇术组合:优先携带奇术"千灯一月"可完美触发"阴阳迷踪" |
| **惧刃 / 铁衣戍魂** | 裂石钧 | 双切轴的核心 buff(唤千军拿 30 秒铁衣戍魂,双惧刃轴) |
| **九重春色 / 明川药典 / 无名剑法 等** | 定音前缀 | 都是心法名,定音增伤与对应心法绑定 |

## 六、输出时避免的"外行说法"

1. ❌ "暴击率" → ✅ 会心率 / 会意率(并注意先过精准判定)
2. ❌ "暴伤" → ✅ 会意倍率(橙字)或会心伤害加成
3. ❌ "洗词条 / 重铸" → ✅ 调律;指定改一条叫转律
4. ❌ "元素伤害" → ✅ 属性攻击(破竹/裂石/鸣金/牵丝/无相等按流派划分)
5. ❌ "附魔" → ✅ 定音
6. ❌ "面板攻击力"笼统说法 → ✅ 区分大外(最大外功)/小外(最小外功)
7. ❌ 把流派当"职业"表述 → ✅ 燕云流派由**武器+心法组合**构成,可换装切换,不存在固定职业
8. 五维是**体、劲、御、敏、势**(不是力敏体智精),详见 [五维属性说明.md](五维属性说明.md)
